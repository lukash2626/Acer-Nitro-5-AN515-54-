# PadelUp WordPress Theme

Тема для интернет-магазина падельного инвентаря.

## Установка

1. Загрузите папку `padelup-theme` в `/wp-content/themes/`
2. Активируйте тему в админке WordPress
3. Установите плагины WooCommerce и Elementor

## Возможности

- Полная интеграция с WooCommerce
- 8 кастомных Elementor виджетов
- Адаптивный дизайн
- AJAX добавление в корзину
- Кастомайзер для настройки контактов и баннеров

## Структура

- `style.css` - Основные стили темы
- `functions.php` - Функции темы
- `header.php` / `footer.php` - Шапка и подвал
- `front-page.php` - Главная страница
- `inc/` - Инклуды (кастомайзер, Elementor, шаблонные функции)
- `woocommerce/` - Шаблоны WooCommerce
- `templates/elementor/` - JSON шаблоны для Elementor
