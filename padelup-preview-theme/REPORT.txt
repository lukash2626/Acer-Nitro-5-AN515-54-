1. ИСПРАВЛЕНИЕ КНОПКИ «ВЫЙТИ»
========================================

Файл: woocommerce/myaccount/navigation.php

Проблема: Кнопка «Выйти» в личном кабинете не работала — при нажатии ничего не происходило.

Причина: Ссылка использовала wc_get_account_endpoint_url('customer-logout'), который генерировал URL через WooCommerce endpoint. Если nonce истекал или endpoint был некорректно настроен, ссылка не работала.

Исправление: Заменено на wc_logout_url(home_url()) с fallback на wp_logout_url(home_url()). Это стандартный WordPress-механизм выхода, который работает надёжнее.

Код до:
  $logout_url = wc_get_account_endpoint_url($endpoint);

Код после:
  $logout_url = function_exists('wc_logout_url') ? wc_logout_url(home_url()) : wp_logout_url(home_url());
  echo '<a href="' . esc_url($logout_url) . '">' . esc_html($label) . '</a>';

3. ИСПРАВЛЕНИЕ ШИРИНЫ ФОРМ ВХОДА/РЕГИСТРАЦИИ
========================================

Файлы: style.css, woocommerce/myaccount.php

Проблема: Формы входа и регистрации были сильно узкими.

Причина: Страница /moj-akkaunt/ проходила через page.php (а не через шаблон myaccount.php). Обёртка .page-content имела max-width: 800px, что сужало формы.

Исправления:
  a) Добавлен CSS-класс: .woocommerce-account .page-content { max-width: 100%; }
  b) Формы получили flex: 1 1 50% !important и max-width: none !important
  c) Контент WooCommerce: width: 100% !important
  d) В myaccount.php убран инлайн style с max-width: 1200px, заменён на CSS-класс myaccount-container

4. ИСПРАВЛЕНИЕ КОРОЗИНЫ
========================================

Файл: woocommerce/cart/cart.php

Проблема 4.1: Отсутствовала кнопка «Оформить заказ».
Причина: Блок cart-collaterals сwoocommerce_cart_totals() не был включён в шаблон.
Исправление: Добавлен вызов woocommerce_cart_totals() внутри cart-collaterals.

Проблема 4.2: Товары и итоги шли вертикально друг за другом.
Исправление: Перестроен макет:
  - Товары по центру (max-width: 800px)
  - Блок суммы + «Оформить заказ» ПОД товарами
  - На мобильных — на всю ширину

CSS:
  .cart-layout { display: flex; flex-direction: column; gap: 30px; max-width: 800px; margin: 0 auto; }

Проблема 4.3: Названия товаров обрезались.
Причина: CSS использовал -webkit-line-clamp: 2 и overflow: hidden.
Исправление: Убрана обрезка, добавлен word-break: break-word.
